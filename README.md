# Payroll Management System

A simple and professional **Payroll Management System** frontend built for managing employee payroll, attendance, and salary information.

## Project Overview

This is a mini project that demonstrates a complete payroll management solution with separate interfaces for:
- **Admin Dashboard** — Manage employees, process payroll, view reports
- **Employee Dashboard** — View payslips, check attendance, manage profile

###  Features

### Admin Features
- Dashboard with employee statistics
- Total employees count
- Payroll processed tracking
- Pending requests management
- Quick actions for common tasks
- Recent activity log
- Payroll summary and analytics

### Employee Features
- Personal dashboard with salary information
- View payslips with detailed breakdowns
- Check remaining leave balance
- View tax deductions
- Upcoming holidays calendar
- Quick access links
- Net salary calculation

##  Technologies Used

- **HTML5** — Page structure and markup
- **CSS3** — Styling and responsive design
- **JavaScript (Vanilla)** — Interactive functionality
- **Font Awesome** — Icons and visual elements
